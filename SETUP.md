# Nima GitHub Profile Setup

1. Create a **public** repository named exactly `nimadevlog`.
2. Copy all files from this package into that repository, including the hidden `.github` folder.
3. Commit and push.
4. Open the repository's **Actions** tab.
5. Run **Update contribution snake** manually once.
6. Open `https://github.com/nimadevlog` to see the profile README.

## Important

The README intentionally does **not** include:
- Profile views
- GitHub streak
- A large top banner
- A top-right terminal box

It does include:
- GitHub statistics
- Contribution activity graph
- Contribution snake workflow
- Most-used-language chart
- Animated typing text
- Tech stack
- Currently Coding section
- WakaTime placeholder
- Featured Projects section
